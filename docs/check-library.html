Reference for every check in CHECK_CATALOG (249 entries). Safe checks use either signed bounded probes or explicit E1 declaration-only records; E1 never means live-tested. How a check runs

  1. Declare target group + target (FQDN/IP/URL).
  2. Start test run — planner picks check, creates signed probe job(s).
  3. Probe worker executes a bounded probe (probe_profile) against the declared target only, or records not_run with zero I/O for an E1 metadata_marker.
  4. Correlation compares external_result vs the check's default_expected_behavior → verdict + finding (external probe evidence only).
