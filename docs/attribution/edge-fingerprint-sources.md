# Edge Fingerprint Source Attribution

The vendored edge-fingerprint corpus in `src/lib/data/edgeSignatureData.mjs` is **generated** —
do not edit it by hand. It is regenerated by:

```bash
node scripts/generate-edge-signatures.mjs --wafw00f <wafw00f clone> --cdncheck <cdncheck clone>
```

## Tier policy

Upstream wafw00f classifies some signatures by whether they only fire on a response the WAF
produced when *rejecting* a request (their plugins mark them with `attack=True` or rely on
block-only status codes). AstraNull preserves that split as two tiers:

| Tier | Meaning | AstraNull evaluation rule |
|---|---|---|
| `passive` | Decidable from one ordinary GET response (header/cookie markers) | Evaluated on any bounded response snapshot |
| `block_page` | Describes what a WAF returns when it rejects a request (content/status/reason) | Evaluated **only** against block evidence an authorized bounded check already captured. AstraNull never sends attack payloads to manufacture this evidence. |

cdncheck address/CNAME data is evaluated metadata-only: IP family + CIDR membership and CNAME
suffix matching. No DNS lookups or HTTP requests are performed by the classifier itself.

## Regeneration

1. Clone both upstream repositories (shallow clones are fine).
2. Run the generator with both clone paths (see command above).
3. Confirm the reported `unparsed calls` count is `0`; investigate any drift before shipping.
4. Bump `EDGE_SIGNATURE_CORPUS_VERSION` in `src/lib/edgeFingerprint.mjs` when the corpus
   content changes.
5. Run `npm test` — `tests/unit/edge-signature-corpus.test.mjs` validates corpus integrity
   and the payload-free guarantee.
